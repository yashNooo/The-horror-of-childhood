# Horror of Childhood

A dark archive website for the Minecraft mods, creepy videos, horror games, and movies that made childhood feel a little unsafe.

## About

**Horror of Childhood** is a horror themed website where users can explore scary Minecraft content, nostalgic horror games, creepy movies, and childhood horror memories. I personally added the games / movies that scared the hell out of me in my childhood.

## Features

- Background music with play/pause button in bottom right corner
- Categories for Minecraft horror mods, videos, games, and movies
- Card hover effect
- Suggestion inside every category
- Suggestions are received through Formspree


## Built With

- HTML
- CSS
- JavaScript
